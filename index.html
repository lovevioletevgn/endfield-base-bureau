明日方舟：终末地 · 基建工具

终末地基建知识库

从游戏配置表提取的基建数据包，配一个可交互的查询界面和产线自动排布器。 建筑占几格、接口在哪条边、传送带吞吐多少、这条产线怎么摆 —— 一次查完。

打开在线版 → 本地运行 在线版打开即用，无需注册与安装。

这个工具能做什么

占地蓝图

每座建筑的宽×深×高格数、面积、外圈周长，以及每个进料/出料口的格坐标与所在边。接口用 SVG 俯视图画出，对齐游戏蓝图预览的观感。

产线排布器

选一个目标产物，自动解出配方树、规划机器摆放、布线连接，输出一份可直接照着搭的布局，附连通率与原料闭环报告。

配方与物品链路

机器 / 建造 / 手工三张配方表联合查找，任一物品都能双向追溯上下游，不会漏掉只在建造表里出现的中间产物。

物流与玩法规则

传送带与管道的吞吐速率、连接长度与角度限制、暗管配对规则、区域锁定与矿物无线传输条件，每条规则附配置表原文出处。

本地运行

在线版是托管页面；如果想离线用、或者自己改，clone 仓库后本地构建即可。 产物是单个 HTML 文件，内联了全部数据和算法，双击就能开，不依赖网络。 

git clone https://github.com/1595745135/endfield-base-bureau.git
cd endfield-base-bureau
python tools/build_html.py      # 生成 终末地基建查询.html
node   tools/test_html.js       # 回归测试
为什么仓库里没有那个 HTML？ 它是构建产物，可由 data/ 与 tools/ 完整重建， 因此不纳入版本控制（否则每次改动都产生 1.4 MB 的 diff，git 历史会迅速膨胀）。 仓库里放的是能造出它的东西 —— 数据、源码和构建脚本。

命令行也可以直接查，不必开界面： 

python tools/ake.py 蓝图 精炼炉      # 占地格数 + 接口平面图
python tools/ake.py 树 息壤          # 追溯完整上下游链
python tools/ake.py 规则 无线        # 搜规则，附原文证据
python tools/ake.py 基地             # 各基地建设区面积与建造上限

数据分层与版权

本项目的文件按版权归属分三层，这决定了哪些能进版本库：

层体量进仓库说明
游戏解包配置表 18.4 MB 否 含游戏内文案原文，版权归鹰角网络，不外传、不上云
烘焙派生参数 36 KB 是 从配置表提取的数值（环境色、散布机规格、可出货物品清单），替代对解包目录的依赖
清洗后数据包 + 源码 约 1.9 MB 是 结构化数据与本项目的构建 / 测试脚本

因此，没有解包数据的机器（新 clone 的副本）也能完整构建出字节完全一致的产物。

游戏数据版权归鹰角网络及相关权利方所有。本项目仅供学习、交流与研究使用； 本知识库只收录配置表中的静态数据，矿脉产率、建设值收益等运行时数值不在配置表内，需游戏内实测。
