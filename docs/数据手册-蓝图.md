### 单位口径 —— 先看懂这个，再看数据

| 字段 | 含义 | 能不能用于蓝图 |
|---|---|---|
| `range.width / depth / height` | **整数格**。宽×深=地面占格，高=占用格高 | ✅ **蓝图摆放依据** |
| `modelHeight` | 模型实际高度（**小数**，单位米） | ❌ 纯视觉，蓝图不要用 |

> 实测：天有洪炉 `modelHeight`=4.4 而 `height`=5，两者不是一回事。全局有 20 处不一致，**一律以 `width/depth/height` 为准**。

### 接口坐标 —— 决定"线怎么接"

每座建筑的 `inputPorts` / `outputPorts` 带每个接口的**格坐标**：

- `x` 沿 width 方向（0 ~ W-1）
- `z` 沿 depth 方向（0 ~ D-1）
- `y` 为高度层（如精炼炉的管道口在 y=3，地面传送带口在 y=0）
- `isPipe`：`true`=管道口，`false`=传送带口

**边名用格坐标（`z=0` / `z=D-1` / `x=0` / `x=W-1`），不是东南西北。** 配置表里没有证据能把 x/z 轴对应到游戏内的绝对方位，所以本库不声称方向。蓝图层面需要的信息（口在哪条边、每条边几个接口）完全不受影响。

> 角上的接口会同时命中两条边，因此各边计数之和大于接口总数。`mixedSides` 只在进/出料口占用**完全相同**的边集合时为 `true`。

### 占地平面示意：SVG 俯视图（2026-09-20 起取代 ASCII 字符画）

「占地蓝图」页展开任意一座设施，接口布局现在是 **SVG 俯视图**：网格 + 建筑外框 + 接口方块/圆点 + 朝外的接口引线，观感对齐游戏蓝图预览。

| 图形 | 含义 |
|---|---|
| 绿色实心方块 `I` | 进料口（传送带） |
| 浅绿圆点 `i` | 进料口（管道，虚线引线） |
| 棕色实心方块 `O` | 出料口（传送带） |
| 浅棕圆点 `o` | 出料口（管道，虚线引线） |
| 红色方块 `×` | 同格多口（多种/多个口挤同一格） |
| 外圈短线 | 口朝哪条边外 |

- **为什么不用游戏贴图**：游戏蓝图分享码解不开（见下一节），贴图有版权，而且要保持单文件离线可用。做法与社区工具一致 —— `zmd-bp-tool`、`t2blueprint`、`IndustrialPlanner`、endfieldtools 的工厂规划器全都是自己画矢量网格 + 建筑外框 + 传送带线，没人嵌游戏贴图。
- 颜色只表达 进/出 与 传送带/管道；边名仍是格坐标（`z=0` / `x=0` …），**不声称游戏内绝对方位**。
- 建筑本体按**分类配色 + 分类字标**（采/炼/组/流/电/储/御/饰），比纯白框更接近游戏卡面观感。分类色与字标是自绘的，不是游戏贴图。
- 测试有断言守着：确实是 SVG、接口形状数量 = 去重后的接口格位数、ASCII 版已移除。

### 布局试摆（交互沙盘，2026-09-20 新增，2026-09-21 加进阶操作）

「布局试摆」标签页：左栏点选建筑 → 右边画布点击摆放（吸附网格）。可以选画布尺寸 **40×40 / 50×50 / 70×70 / 80×80**（正好对应副/主基地边长），实时显示「已放几座、占地几格、剩余几格」。

**操作表**（2026-09-21 补）：

| 想干什么 | 怎么操作 |
|---|---|
| 摆放 | 左栏点建筑 → 点画布空白处（越界/重叠会被挡下并给提示） |
| 单个选中 | 单击已放建筑（选中态是暖色描边） |
| 删除单座 | 双击该建筑（或选中后按 `Del`） |
| 批量框选 | 在**空白处按住拖拽**出橡皮筋矩形，松手选中框内所有建筑 |
| 批量移动 | 拖住任意一座选中建筑，整组跟着走（碰撞会整组挡回） |
| 批量旋转 | `R`（或按钮）：绕选区外接矩形中心整体转 90°，**接口跟着转** |
| 复制一组 | `Ctrl+D`：整组往右让一个身位，右边放不下就往下，都放不下则提示 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`（按钮上也有），栈深 80 步 |
| 加选 / 减选 | `Shift` + 单击 |
| 取消选中 | `Esc` 或点空白处 |

- **左栏默认只列「能进基地产线」的基建**（2026-09-21 需求）：**生产**（基础加工 8 + 组件加工 13）、**电力**（电力设施，见下）、**存储物流**（仓储物流 13 + 物流辅助 9），外加**核心结构 4 件**（协议核心 / 次级核心 / 产物排出口 / 污水接入口）—— 共 **50 座**。资源采集（矿机/水泵只能放野外矿点）、防御设施、装饰（田块/玩偶/立牌）默认不列；要单独看某类，用上方分类下拉选，左栏顶部有「回到默认三类」。
  > 核心结构是**按 ID 放行**的例外：`quickBarType` 为空被归进「装饰与其他」，但 9×9 占地 + 20 个接口，基地布局绕不开它。放行名单写在 `LO_KEEP_IDS` 里（不按中文名匹配）。
  > **中继器（`power_pole_2`）+ 息壤中继器（`power_pole_3`）已按要求拉黑**（`LO_SKIP_IDS`），默认清单和分类下拉两条路都不给 —— 电力设施因此只剩 3 台（供电桩 / 息壤供电桩 / 热能池）。要放回来就把 ID 从 `LO_SKIP_IDS` 删掉。
- **旋转的意义在接口，不在外框**：宽深互换只是顺带（3×5 → 5×3），真正有用的是进料口/出料口换边 —— 接口格坐标按 `(x,z) → (d-1-z, x)` 顺时针转，所以能直接看出"转过来之后进料口在哪条边"。
- 多选旋转是**刚体整体旋转**（游戏里也是这样），转完若越界或压到别的建筑，整组取消并提示，不会留下半转状态。
- 撤销栈存的是**尺寸 + 摆放**的整块快照，所以「换画布尺寸（会清空）」也能退回去。
- 只做**占地试摆**，**不做传送带/管道连线** —— 连线数据是玩家实际布局，不在配置表内。
- 不做「保存蓝图 / 导出蓝图码」（2026-09-21 定：不需要此功能）。
- 用 `getBoundingClientRect` 反算点击格位，纯 DOM/CSS，无外部依赖，仍是单文件离线可用。
- **鼠标优先**：拖拽框选/拖动走 `mousedown/mousemove/mouseup`。手机/平板上点按仍能摆放与选中，但"按住拖拽"在触屏上等于滚动页面，框选体验不保证。
- 为什么不做游戏贴图：见上 —— 蓝图码解不开 + 版权 + 离线。等价替代就是自绘矢量（网格 + 外框 + 分类字标 + 接口点）。
- 回归测试：`node tools/test_html.js`（渲染 + 纯函数：摆放/碰撞/旋转/撤销/框选判定 212 条）与 `node tools/test_layout_events.js`（**事件层**：拖拽框选、拖动移动、双击删除、快捷键，38 条）。后者用迷你 DOM 把鼠标事件真跑一遍 —— 这次就是它抓出「改成 pointer 流程后，点画布摆放这条路径断了」的。

### 经验规律：加工机的进出料朝向

**进料口在 `z=D-1` 边，出料口在 `z=0` 边**（传送带）。精炼炉、配件机、粉碎机、封装机、拆解机、灌装机、研磨机、天有洪炉、反应池都符合。

通信口径统计（全部 48 座带接口建筑）：

| | z=0 | z=D-1 | x=0 | x=W-1 |
|---|---|---|---|---|
| 进料口 | 15 | **98** | 49 | 17 |
| 出料口 | **87** | 1 | 26 | 48 |

**但这条规律并非全员适用** —— 储液罐/储气罐是 `x=0` 进、`x=W-1` 出（管道）；协议核心是 z 两端进、x 两端出。**以每座建筑自己的接口数据为准。**

### 典型布局示例

**精炼炉 3×3，8 个接口** —— 最典型的三面布局：

```
      0 │ O O O        z=0 边：3 个出料口（传送带）
      1 │ i · o        x=0 边：1 个进料口（管道，y=3）
      2 │ I I I        x=W-1 边：1 个出料口（管道，y=3）
        └─────         z=D-1 边：3 个进料口（传送带）
```

**协议核心 9×9，20 个接口** —— 环形布局，中央 5×5 是设备本体：

```
      0 │ · I I I I I I I ·     z=0 边：7 进
      1 │ O · · · · · · · O     x 两端：各 3 出
      ...
      8 │ · I I I I I I I ·     z=D-1 边：7 进
        └─────────────────
```
